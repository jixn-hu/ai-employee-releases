# AI 超级员工

面向 Windows 的 AI 员工工作空间：招聘员工，通过聊天安排工作，按需分配插件和账号，查看结果。

## 下载

**[下载最新版本](https://github.com/jixn-hu/ai-employee-releases/releases/latest)**

打开发布页，下载 `AIEmployee-Setup-<版本>-x64.exe` 并安装。从桌面「AI 超级员工」启动，无需安装 Node.js。

需要免安装版时，可下载发布附件中的 `AIEmployee-Windows-x64.zip`，完整解压后运行程序。GitHub 自动生成的 Source code ZIP 不是桌面安装包。

## 开始使用

1. 在「模型与设置」配置自己的模型接口和 API 密钥。
2. 招聘员工，选择岗位与能力。
3. 在插件中配置服务，并将需要的账号或连接分配给员工。
4. 通过聊天安排工作，查看员工交付的结果。

支持员工协作、定时工作、长期记忆、网页阅读、资讯监控、图片生成、内容发布、邮箱、本地文件与服务连接。外部服务需自行配置账号和凭据。

## 软件更新

在「模型与设置 → 软件更新」检查新版本。下载并通过校验后，点击「重启并安装」；有工作正在执行时会提示稍后安装。

更新来源为 `jixn-hu/ai-employee-releases`。公开下载和更新无需 GitHub 登录或访问令牌。

用户数据保存在 `%APPDATA%\digital-world-desktop`，升级与卸载保留原有员工、聊天、任务和配置。

## 仓库用途

这是独立的**公开下载与更新仓库**，维护程序发布附件、版本说明和使用说明。PC 源码在独立私有仓库维护。

程序包不附带个人账号、模型密钥或工作数据。
